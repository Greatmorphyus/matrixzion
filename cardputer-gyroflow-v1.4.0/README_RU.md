# Cardputer ADV Gyroflow Logger v1.4.1

Версия 1.4.1 сохраняет проверенное ядро гироскопа v1.3.1, организацию файлов по сессиям и управление видеозаписью Canon через Bluetooth. В этой версии заменён BLE-транспорт на NimBLE и исправлено защищённое сопряжение современных Canon.

## Первый запуск

1. Вставьте microSD.
2. Запустите прошивку и держите Cardputer неподвижно во время калибровки.
3. На экране SESSION SETUP введите имя съёмки, до 12 символов.
4. Нажмите Enter или GO.
5. Будет создана новая папка, например /GYRO/NIGHT.
6. При повторном имени создаётся NIGHT_02, затем NIGHT_03. Старые файлы не перезаписываются.

Файлы внутри папки:

- NIGHT_001.gcsv
- NIGHT_002.gcsv
- NIGHT_003.gcsv

Дата и время не используются.

## Подключение Canon R50 V

1. На R50 V откройте `Communication functions > Connect to wireless remote`.
2. Выберите добавление нового пульта и оставьте камеру на экране ожидания, где она просит зажать кнопки `1 + 2` или `W + T`.
3. На Cardputer нажмите `P` один раз.
4. Дождитесь `CAM READY`, затем подтвердите завершение на камере кнопкой `SET`.

Первое сопряжение занимает до 20 секунд. Адрес и тип адреса камеры сохраняются во внутренней памяти. Нажатие `P` во время калибровки ставится в очередь и запускается сразу после неё.

Статусы:

- CAM READY: камера подключена
- P TO PAIR: камера ещё не сопряжена
- CAM LINKING: идёт подключение
- SCAN CAMERA: Cardputer ищет рекламу службы BR-E1
- CAM FOUND: R50 V найдена
- CAM SECURE: создаётся защищённое BLE-соединение и bond
- CAM IDENT: Cardputer передаёт камере имя пульта
- CAM READY: сопряжение и доступ к управлению подтверждены

Коды ошибки после неудачной попытки:

- E3 NOT FOUND: камера не находилась на экране сопряжения или не рекламировала службу BR-E1
- E4 CONNECT: BLE-соединение не установилось
- E5 SECURE: камера отклонила защищённое сопряжение
- E8 ID WRITE: камера не приняла идентификатор пульта
- E9 CONTROL: служба управления записью недоступна

При E5 или E8 удалите старый беспроводной пульт в настройках камеры, выключите камеру, выньте аккумулятор на несколько секунд, включите и повторите шаги выше.

## Запись

GO, G или Space запускают цикл:

1. Открывается новый GCSV.
2. Гироскоп начинает запись.
3. Проходит 1 секунда pre-roll.
4. Cardputer отправляет камере команду начала видео.

Повторное нажатие:

1. Cardputer отправляет камере команду остановки видео.
2. Гироскоп пишет ещё 1 секунду post-roll.
3. GCSV закрывается.

BLE работает в отдельной низкоприоритетной задаче. Поток BMI270, аппаратный FIFO, sensor time, очередь SD, масштаб GCSV и ориентация Zxy сохранены из v1.3.1.

## Управление

- GO, G, Space: запуск или остановка общей последовательности
- P: сопряжение Canon
- N: новая съёмочная сессия
- C: калибровка гироскопа
- D: диагностика
- R: повторное подключение microSD

## Проверка дубля

Исправная запись показывает:

```text
RATE 800.0 Hz
CLOCK LOCK
MISS 0
DROP 0
```

При CAMERA READY команда Canon отправлена успешно. Камера должна быть в режиме Movie и иметь включённый Bluetooth Remote Control.

## Gyroflow

Откройте видео, затем соответствующий файл SESSION_XXX.gcsv. Формат определяется как M5Stack community firmware. Ориентация уже записана как Zxy. Метод интеграции VQF. Для мелкой дрожи начните с low-pass 50 Гц.

## Сборка

```bash
pio run
```

Готовый файл: .pio/build/m5stack-stamps3/firmware.bin
